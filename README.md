# deej

A public collection of software, AI skills, and things I learn along the way.

This repository is a place to share useful tools, reusable workflows, experiments, and practical notes. The aim is to make what I build and learn easy for others to explore, use, and build on.

## What belongs here

- **Software:** Tools, scripts, and small projects that solve practical problems.
- **Skills:** Reusable instructions that help AI assistants carry out specific tasks.
- **Learnings:** Notes, explanations, and lessons from building, exploring, and trying things out.

The collection will grow over time. For now, it starts with ELIC.

## Explore and reuse

Browse the files directly, or clone the repository:

```sh
git clone https://github.com/deejdan/deej.git
cd deej
```

Read the instructions and license for the item you want to use. For AI skills, follow your assistant’s skill-loading conventions or use the instructions as a reference for your own workflow.

## Feedback and contributions

Found a mistake, have an improvement, or want to share something useful? Open an issue or a pull request. Include enough context for someone else to understand the problem and try your suggestion.
